# Apertus Legal and Transparency Documentation

This repository contains the legal and transparency documentation for the [Apertus models](https://apertus-ai.org), including the current License, Usage Policy, Code of Conduct and the Public Summary of Training Content.

We publish these materials openly to help users understand how Apertus may be used responsibly and how the models were developed. They provide guidance on acceptable use and transparency around training data, data sources, copyright-related safeguards, and relevant obligations under the EU AI Act.

Please visit our websites for more information.

Swiss AI Initiative: https://swiss-ai.org
Apertus: https://apertus-ai.org
